# Contributing

1. Use a focused branch from the current base. Describe the change, its purpose, and how it was verified.
2. Update affected design contracts, reference links, figures and status in the same review. Keep examples clearly labeled and update the figure source and its export together.
3. For documentation, verify relative paths, heading references, accessible captions and source citations. Check each revised figure at reading width.
4. When code is implemented, run the relevant tests with synthetic fixtures and record commands and outcomes. For an experiment, include dataset version, split, seeds, configuration and uncertainty.
5. Keep raw datasets, customer identifiers, secrets, and bulky experiments outside commits. Report findings with sufficient provenance and clear limitations.

See the project [README](README.md) and [system design](docs/system-design.md).

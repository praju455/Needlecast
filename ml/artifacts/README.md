# Artifact contracts and fixtures

Run `make schemas` after changing the typed artifact contract. Run `make sample-artifacts` to generate the deterministic fixtures and `make validate-artifacts` to check them.

The JSON in `sample/` is placeholder data. Fields such as scores, times, metrics, and cost figures illustrate payloads. The circuit SVGs are also illustrative. See the [placeholder data policy](../../docs/stub-data-policy.md).
